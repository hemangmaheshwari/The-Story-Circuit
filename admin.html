How to Update Your Live Vercel Website

The changes you save on this page are stored instantly in your local browser cache for previewing. To make these changes permanent and visible to the public on Vercel:

  1. Click the "Export data.json" button at the top right.
  2. A file named data.json will download.
  3. Go to your website repository (e.g. on GitHub).
  4. Upload and overwrite the existing data.json file in the root folder.
  5. Once pushed, Vercel will automatically detect the file change and rebuild your live site within seconds!
